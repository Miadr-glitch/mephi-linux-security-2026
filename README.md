# MEPHI Linux Security 2026

Практическая работа по администрированию и безопасности Linux на Fedora.

Выполненные задания:
1. Создание пользователя user1 и настройка срока действия пароля.
2. Поиск SUID-файлов и процессов с разными RUID/EUID.
3. Демонстрация механизма SUID.
4. Настройка Linux capabilities.
5. Настройка sudo для управления системным временем.
