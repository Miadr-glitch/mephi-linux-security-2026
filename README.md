# mephi-linux-security-2026
Практическая работа по безопасности Linux
У меня возникла проблема с виртуал боксом я переделал работу  из-за этого  со страой работы снимки тоже прикреплю

| 1 | Управление пользователями и группами | passwd.txt, group.txt |
| 2 | Поиск SUID-файлов и мониторинг процессов | suid-files.out, find-files.out, processes.out |
| 3 | Изучение механизма set-UID | stat.out |
| 4 | Изучение Linux Capabilities | getcap.out |
| 5 | Настройка sudo | sudoers.txt |
| 6 | Сбор результатов | history.out, mephi-screenshot.png |
## Дополнительные файлы
- processes-all.out — список процессов
- stat.out — информация о правах и файлах
- history.out — история команд
Практическая работа выполнена в Fedora Linux в VirtualBox.
